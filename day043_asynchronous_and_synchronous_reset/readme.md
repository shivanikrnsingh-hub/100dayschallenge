**Asynchronous and Synchronous Reset**

**Description:**

This module demonstrates the two fundamental ways to initialize or "reset" a flip-flop.

**Asynchronous Reset:**

The reset signal is independent of the clock; the output is cleared immediately when the reset is asserted.

**Synchronous Reset:**

The reset is sampled only on the active edge of the clock, leading to cleaner timing in high-speed designs.
